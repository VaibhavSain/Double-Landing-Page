# 🌐 Double Landing Page

A modern and responsive **Double Landing Page** built using **HTML, CSS, and JavaScript**.
This project showcases a split-screen layout with smooth transitions, interactive hover effects, and clean UI design.

---

🔗 **Check it out here:**

## 📌 Features

* 🎨 Modern and clean UI
* ⚡ Smooth hover transitions
* 📱 Fully responsive layout
* ✨ Minimal and lightweight
* 🔀 Split-screen interface
